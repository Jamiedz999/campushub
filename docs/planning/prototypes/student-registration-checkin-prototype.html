Reaction wanted — the sharpest gap this prototype found Promotion is silent. Notifications are out of scope, so a student promoted the night before an event finds out only if they happen to open the page. Three ways out:
  1. Accept it. The dashboard still shows conversion; the story still works.
  2. Add an in-app inbox — cheap, no email infrastructure, visible on next open.
  3. Reinstate a confirmation step, which decision 04 deliberately rejected.
