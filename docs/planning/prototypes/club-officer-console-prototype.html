Club officer console — throwaway prototype

Desktop surface, state gallery. Not code to keep. Shows the officer's path from creating an Event to reading its attendance, with the failure states the resolved decisions actually produce.

Reaction wanted Rescheduling takes the new slot before releasing the old, so a failure mid-way leaves the club holding two rooms. Should the console surface that (“you are holding 2 slots — release the old one”) or clean it silently on next view?
