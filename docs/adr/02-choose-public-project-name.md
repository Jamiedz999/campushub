# Choose the public project name

Type: grilling
Status: resolved
Blocked by: 01

## Question

Which of the screened names becomes this project's public name, and what is its one-line positioning sentence?

The choice fixes the repository name, the Java base package, the Docker image name, the deployed hostname and the name that appears on the resume, so it must be settled before the technical baseline. Confirm whether the placeholder directory `campushub/` is renamed and whether `CampusHub` survives the screen as the chosen name.

## Answer

**The name is `CampusHub`.** The positioning sentence is:

> Campus club events, from signup to the door.

The placeholder directory `campushub/` is **not** renamed.

`CampusHub` did not pass the collision screen in [naming research](../planning/research/01-research-project-name-collisions.md); it is adopted anyway. Naming is not where this project earns its score, and the cleaner alternatives the screen produced were not worth the effort of switching.

### Consequences

- Repository `CampusHub`; Java base package `com.campushub`; Docker image `campushub`.
- Ticket 12 (technical baseline) is unblocked with respect to naming.
